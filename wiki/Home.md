# PyAct CLI Wiki

Welcome to the official wiki for the **PyAct CLI**! 

PyAct is a lightweight but extremely powerful compiler that allows you to write interactive, programmable Markdown files (`.pamd`) that execute Python code natively to generate dynamic content, mathematical equations, nested components, and highly styled Microsoft Word documents.
